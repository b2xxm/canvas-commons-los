# Canvas Commons Animation

> *Project is still in early development*

This repository contains the source code behind the animation that visualises the development of my line-of-sight system.

## About

The motivation behind this project was to present my system in a visual, appealing, and intuitive way, whilst also undertaking a new project and learning a new language.

Having no prior experience for animation or animation software, and a preference for manually controlling the animation process, I decided to turn to code-based animation.
This approach allows for signal-driven animations, precise calculations, and greater control over the timing and behaviour of each animated object.

My inspiration and introduction to Motion Canvas stems from [aarthificial's](https://www.youtube.com/@aarthificial) devlogs, where he regularly uses and advocates for the framework.
